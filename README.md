# 亲邻记事 · 家庭事务看板 (Family Affairs Hub)

> 一个专为家庭设计的极简、高颜值、多端响应式家庭事务管理看板。支持多成员、多分类、待办清单/看板、成熟美观的开源日历（FullCalendar）、自定义生活照头像以及 PushPlus 微信提醒与每日早报。

---

## ✨ 核心特性

### 1. 👨‍👩‍👧‍👦 家庭成员与专属辨识
* **预置 6 位核心成员**：我、我的配偶、小宝、大宝、爷爷、奶奶，以及全家公共事务。
* **自定义生活照头像**：支持手机或电脑相册直接上传照片，系统内置自动圆形居中裁剪与高质量压缩；也支持一键点选卡通 Emoji。
* **专属色彩标记**：每位家庭成员拥有专属主题色，在日历与待办中一眼辨识。

### 2. 📋 多视图自由切换
* **待办清单视图**：大拇指友好的卡片列表，一键打勾完成（带彩带特效），逾期红字高亮提醒，支持按分类与成员过滤。
* **看板模式 (Kanban)**：PC 宽屏下一键切换【待处理】、【进行中】、【已完成】三列看板。
* **开源成熟日历视图 (FullCalendar 6)**：
  - 集成前端最成熟公认的开源 FullCalendar 日历；
  - 成员专属色块标注，支持月视图、周视图、日程清单；
  - 点击日历空白日期直接极速记事，点击日程查看详情。
* **家庭成员矩阵视图**：卡片式呈现家庭成员各自的待办概览，支持一键「给某某记一笔」。

### 3. 🛡️ PushPlus 微信提醒与每日早报（防遗忘体系）
* **即时微信提醒**：新增或修改紧急待办时，勾选即可立即推送微信通知。
* **一键微信催办**：每条待办卡片均有一键「微信提醒」快捷按钮。
* **今日家庭早报**：自动汇总今日各成员事务与逾期警示，生成精美卡片推送到微信。
* **免服务器定时早报**：已内置 `.github/workflows/daily-family-digest.yml`，推送到 GitHub 后可免费每天早上 8:00 自动推送到微信。

### 4. 📱 深度适配手机与 PC 端
* **手机端**：底部原生体验 Tab 栏导航，中间悬浮大圆记事按钮，单手握持操作自如。
* **PC 端**：宽屏大看板，顶部侧栏布局，效率拉满。
* **国内访问秒开**：纯静态资源打包，不依赖任何不可达外网服务，国内 CDN 秒开。

### 5. 💾 双引擎数据存储与备份
* **开箱即用零门槛**：默认使用浏览器 LocalStorage 本地持久化，断网可用。
* **一键数据备份**：支持一键导出完整的 JSON 数据备份，或一键导入恢复。
* **云端跨端秒级同步**：支持在设置中配置 Supabase 等轻量云数据库，电脑与手机秒级打通。

## 🚀 快速启动

### 本地开发
```bash
cd family-affairs
npm run dev
```
启动后在浏览器打开本地链接即可访问（同局域网内手机输入电脑 IP 亦可直接秒开体验）。

### 构建打包与部署（如 Cloudflare Pages 或 国内服务器）
```bash
npm run build
```
打包输出目录为 `dist/`，可直接一键部署到 Cloudflare Pages、Vercel 或国内任意静态托管平台，手机和电脑均可随时随地访问。
